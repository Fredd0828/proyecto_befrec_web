# Befrec y Asociados SAS - Proyecto Web

Sitio web profesional de asesoría contable y tributaria en Colombia.

## subir a GitHub (tú ejecutas estos comandos en tu PC):

```bash
# 1. Clonar este repositorio en tu PC:
git clone <URL-de-tu-repositorio>

# 2. O si ya lo tienes:
cd proyecto_befrec_web
git pull origin main

# Para añadir un nuevoremote (solo primera vez):
git remote add origin https://github.com/TU_USUARIO/proyecto_befrec_web.git

# 3. Hacer push:
git push -u origin main
```

## Estructura del proyecto:

```
proyecto_befrec_web/
├── index.html          # Página principal
├── servicios.html     # Página de servicios
├── blog.html         # Blog con artículos
├── quienes-somos.html # Página Quiénes Somos
├── contacto.html     # Formulario de contacto
├── privacidad.html  # Política de privacidad
├── terminos.html    # Términos y condiciones
├── cookies.html      # Política de cookies
├── css/
│   ├── variables.css   # Variables de colores
│   └── style.css       # Estilos principales
├── js/
│   └── main.js         # JavaScript principal
└── blog/
    └── articulo-*.html # Artículos del blog (6 total)
```

## Características:

- Diseño responsive (mobile-first)
- Paleta: negro/gris/blanco con acentos amarillos
- 9 servicios en grid (3 columnas desktop)
- 6 artículos de blog (3 de 2025 + 3 de 2026)
- Botón flotante de WhatsApp
- SEO optimizado con Schema.org
- Banner de cookies
- Header fijo en todas las páginas
- Footer armonioso con 4 columnas

## Tecnologías:

- HTML5 semántico
- CSS3 con variables
- JavaScript vanilla
- Google Fonts (Montserrat, Open Sans)
- Imágenes de Unsplash
